	ASTROGAME
    -----------------

Jeu type arcade dont le but
et de survivre le plus 
longtemps possible face à 
une pluie de météorites.

	---

Configuration requise:
  - RAM : min 4Go

	---

Touches utilisés:
  - click gauche : appuyer sur les boutons et saisir le cadre de pseudo
  - échap : sortir des menus
  - entrer : confirmer la saisie du pseudo
  - flèche gauche : déplacement à gauche du personnage
  - flèche droite : déplacement à droite du personnage
